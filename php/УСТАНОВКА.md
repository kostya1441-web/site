# Установка сайта Hazleton Pumps (PHP + MySQL / phpMyAdmin)

Пошаговая инструкция для обычного хостинга, на котором есть **PHP и MySQL
с панелью phpMyAdmin** (так устроено большинство недорогих хостингов).

## Что понадобится

- Хостинг с поддержкой **PHP 8.1 или новее** и **MySQL 5.7+ / MariaDB 10.3+**.
- Доступ к **phpMyAdmin** (обычно есть в панели управления хостингом,
  например ISPmanager, cPanel, или в личном кабинете хостинг-провайдера).
- Доступ к файлам сайта — через **файловый менеджер** в панели хостинга
  или по **FTP**.

Всё, что нужно редактировать после установки (тексты, картинки, меню,
примеры проектов, статьи) — делается потом через собственную админ-панель
сайта (`/admin`), а не через phpMyAdmin напрямую. phpMyAdmin нужен только
один раз — на этапе установки.

---

## Шаг 1. Создать базу данных

1. В панели управления хостингом найдите раздел «Базы данных MySQL» (или
   похожий) и создайте новую базу данных.
2. Создайте пользователя для этой базы данных и назначьте ему полные
   права на неё.
3. Запишите себе четыре значения — они понадобятся ниже:
   - **хост** (адрес сервера БД — часто просто `localhost`)
   - **имя базы данных**
   - **имя пользователя**
   - **пароль**

## Шаг 2. Загрузить файлы сайта

1. Скачайте папку `php/` из репозитория проекта.
2. Через файловый менеджер хостинга (или по FTP) загрузите **содержимое**
   папки `php/` в корневую папку сайта — обычно она называется
   `public_html`, `www` или `httpdocs`. То есть файл `index.php` должен
   лежать прямо в `public_html/index.php`, а не в
   `public_html/php/index.php`.
3. Убедитесь, что папка `uploads/` внутри загруженного сайта доступна для
   записи (обычно это уже так по умолчанию; если сайт потом не сможет
   сохранять загруженные картинки — see раздел «Если что-то не работает»
   ниже).

## Шаг 3. Импортировать базу данных через phpMyAdmin

1. Откройте phpMyAdmin и выберите слева созданную на Шаге 1 базу данных.
2. Перейдите на вкладку **«Импорт» (Import)**.
3. Нажмите «Выбрать файл», укажите файл **`schema.sql`** из папки `php/`,
   нажмите **«Вперёд» / «Go»**. Это создаст все таблицы.
4. Повторите импорт ещё раз — на этот раз выберите файл **`seed.sql`**.
   Это заполнит таблицы готовым содержимым сайта (тексты на русском и
   английском, фотографии, примеры проектов и т.д.). **Важно: импортировать
   `seed.sql` нужно именно после `schema.sql`, не раньше.**

Если phpMyAdmin спросит про кодировку при импорте — выбирайте **UTF-8**.
(При работе через обычную командную строку, а не через phpMyAdmin, тот же
импорт делается так: `mysql -u имя_пользователя -p --default-character-set=utf8mb4 имя_базы < schema.sql`,
а затем то же самое для `seed.sql` — флаг `--default-character-set=utf8mb4`
важен, без него русский текст на некоторых серверах испортится при
импорте через консоль.)

## Шаг 4. Создать логин и пароль для входа в админку

В phpMyAdmin нет кнопки «хешировать пароль», поэтому логин администратора
создаётся отдельной командой. Если у вас есть доступ по SSH к хостингу —
выполните там:

```bash
php -r "
\$pdo = new PDO('mysql:host=ХОСТ;dbname=ИМЯ_БАЗЫ;charset=utf8mb4', 'ПОЛЬЗОВАТЕЛЬ', 'ПАРОЛЬ_БД');
\$hash = password_hash('ваш-пароль-для-входа-в-админку', PASSWORD_DEFAULT);
\$pdo->prepare('INSERT INTO admin_users (username, password_hash) VALUES (?, ?)')->execute(['admin', \$hash]);
echo \"готово\n\";
"
```

Подставьте вместо `ХОСТ`, `ИМЯ_БАЗЫ`, `ПОЛЬЗОВАТЕЛЬ`, `ПАРОЛЬ_БД` значения
из Шага 1, а вместо `ваш-пароль-для-входа-в-админку` — придумайте
настоящий пароль для входа на сайт (логином будет `admin`, его тоже можно
заменить прямо в команде).

Если доступа по SSH нет — ту же команду можно выполнить на своём
компьютере (если установлен PHP), главное, чтобы он мог подключиться к
базе данных хостинга; либо попросите техподдержку хостинга выполнить этот
один PHP-скрипт.

## Шаг 5. Настроить подключение к базе данных

Откройте файл **`config.php`** (он лежит в корне загруженных файлов) через
файловый менеджер хостинга и впишите туда значения из Шага 1:

```php
define('DB_HOST', getenv('DB_HOST') ?: 'ХОСТ');
define('DB_NAME', getenv('DB_NAME') ?: 'ИМЯ_БАЗЫ');
define('DB_USER', getenv('DB_USER') ?: 'ПОЛЬЗОВАТЕЛЬ');
define('DB_PASS', getenv('DB_PASS') ?: 'ПАРОЛЬ_БД');
```

Сохраните файл.

## Шаг 6. Проверить

1. Откройте в браузере свой домен — должна открыться главная страница
   сайта на английском, с переключателем EN / RU в шапке.
2. Откройте `ваш-домен/admin/login.php` и войдите под логином и паролем
   из Шага 4.

Если всё открылось — установка завершена.

## Что можно редактировать в админке

- **Страницы** — текст и картинки на любой странице, на двух языках сразу;
  можно добавлять и удалять страницы.
- **Меню навигации** — пункты шапки сайта и выпадающие подпункты.
- **Примеры проектов** / **Пресса и статьи** — добавление, редактирование,
  удаление; каждая запись автоматически получает свою страницу на сайте.
- **Настройки и контакты** — телефон, email, адрес, логотип, а также смена
  логина и пароля от самой админки (рекомендуется сменить пароль сразу
  после первого входа).
- **Заявки** — сюда попадают все заполненные посетителями формы
  «Запросить КП» с сайта. Отправка на email не настроена (для этого
  нужны данные от почтового сервера — SMTP), заявки нужно проверять в
  этом разделе вручную.

## Если что-то не работает

- **Сайт открывается, но стили/картинки не подгружаются** — проверьте, что
  папка `assets/` действительно лежит рядом с `index.php` в корне сайта
  (а не на уровень выше/ниже).
- **При сохранении картинки в админке ничего не происходит** — папке
  `uploads/` не хватает прав на запись. В файловом менеджере хостинга
  поставьте ей права `755` или `775`.
- **Страницы открываются только по адресу вида `index.php?...`, а не
  красивыми ссылками** — на сервере выключен `mod_rewrite` или не
  подхватывается файл `.htaccess`. Нужно включить `mod_rewrite` в
  настройках хостинга (обычно это делает техподдержка по запросу, если
  в панели такой настройки нет).
- **Русский текст после импорта показывает вопросики `???`** — при
  импорте через консоль (не через веб-интерфейс phpMyAdmin) забыли флаг
  `--default-character-set=utf8mb4` — см. Шаг 3.
