# Квартирник — сайт кафе-бара (PHP + MySQL + JS + CSS)

## Что реализовано
- Главная, О нас, Мероприятия, Бронирование, Меню, Корзина, Оформление заказа.
- Добавление в корзину, изменение количества, оформление заказа.
- Выбор самовывоза/доставки.
- Демо-блок оплаты ЮKassa (точка интеграции в `api/place_order.php`).
- Админ-панель (демо авторизация): просмотр заказов и смена статусов.
- Подготовлен SQL-дамп `schema.sql` для MySQL.
- Подключение карты Яндекс на странице «О нас».
- SEO-база: `meta description`, семантические заголовки, адаптивная верстка.

## Запуск локально
```bash
php -S localhost:8000
```
Открыть: `http://localhost:8000/index.php`

## Интеграции (как расширить)
- ЮKassa: добавить создание платежа и webhook в `api/place_order.php`.
- Telegram-бот: отправлять уведомление о новом заказе через Bot API после сохранения заказа.
- Личный кабинет и лояльность: добавить таблицы users, bonuses, order_history в MySQL.
