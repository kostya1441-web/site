# Сайт ООО «Адамко Сибирь»

Одностраничный сайт целиком в одном файле — `index.html` (HTML + CSS + JS, без сборки и зависимостей).
Достаточно открыть файл в браузере или положить на любой хостинг.

## Каталог по категориям

Каталог двухуровневый: **категории** → **позиции**.

- Над сеткой — переключатель категорий с количеством позиций и вкладкой «Все категории».
- У категории есть название, код и описание (показывается под вкладками).
- У позиции — фото, артикул, название, характеристики (по одной в строке) и описание.
  Кнопка «Подробнее» открывает карточку позиции с фото и кнопкой обращения.

## Панель администратора

Открывается кнопкой-шестерёнкой справа внизу или ссылкой в подвале.
Пароль по умолчанию — `adamko2026` (константа `ADMIN_PASSWORD` в начале скрипта в `index.html`).

В панели редактируются все тексты сайта и каталог:

- «Каталог — категории»: добавить/удалить категорию, изменить название, код, описание.
- «Каталог — товары по категориям»: позиции сгруппированы по категориям; можно добавить
  и удалить позицию, изменить её поля, загрузить фото с компьютера или указать URL,
  перенести позицию в другую категорию списком «Категория».

Изменения видны на странице сразу, кнопка «Сохранить изменения» записывает их в хранилище,
«Сбросить» возвращает исходное содержимое.

**Где хранятся данные.** Если страница открыта в чате Claude, используется общее облачное
хранилище (`window.storage`) и правки видят все посетители. В обычном браузере данные
сохраняются в `localStorage` — только на этом устройстве. Для общих правок на хостинге
нужен собственный бэкенд: заменить функции `fetchSaved()` и `saveContent()` на запросы к API.

Старый формат данных (плоский список `catalog`) при загрузке автоматически преобразуется
в категории и позиции, сохранённый ранее контент не теряется.

## Анимация

Шестерёнки строятся из SVG-путей в функции `gearMarkup()` и вращаются CSS-анимацией
(`@keyframes sr-spin`): группа из трёх шестерён на главном экране, иконка кнопки админки
(ускоряется при наведении), иконка в шапке панели и индикатор загрузки.
При включённом системном режиме «уменьшить движение» анимация отключается.
