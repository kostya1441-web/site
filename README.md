# Сайт ООО «Адамко Сибирь» — PHP + MySQL

Сайт на PHP с хранением контента в базе данных MySQL (MariaDB). Базой управляют через
phpMyAdmin, текстами и каталогом — через встроенную панель администратора на самом сайте.
Фреймворков и сборки нет: достаточно скопировать файлы на хостинг.

## Состав

```
index.php             — главная (шапка, баннер, превью категорий, услуги, о компании, контакты)
catalog.php           — каталог: фильтр по категориям и карточка позиции
api.php               — вход в панель, чтение и сохранение контента, загрузка фото
config.php            — доступ к базе и пароль администратора
includes/bootstrap.php— подключение к базе, сессия, вспомогательные функции
includes/content.php  — чтение и сохранение контента, работа с таблицами
includes/layout.php   — шапка, меню каталога, подвал, окна
includes/svg.php      — фирменный знак и шестерёнки (рисуются на сервере)
includes/db_error.php — страница «нет связи с базой» с подсказками
assets/site.css       — стили
assets/site.js        — витрина: меню каталога, карточка позиции с галереей
assets/admin.js       — панель администратора
sql/schema.sql        — структура базы и стартовый контент для импорта в phpMyAdmin
uploads/              — сюда попадают загруженные фотографии
```

## Установка на хостинг

1. **Создайте базу.** В панели хостинга или в phpMyAdmin создайте базу с кодировкой
   `utf8mb4_unicode_ci` (например `adamko_sibir`) и пользователя с правами на неё.
2. **Импортируйте структуру и контент.** В phpMyAdmin выберите базу → вкладка **«Импорт»** →
   файл `sql/schema.sql` → «Вперёд». Появятся шесть таблиц с готовым содержимым сайта:
   `settings`, `categories`, `products`, `product_images`, `features`, `stats`.
3. **Пропишите доступы.** В `config.php` укажите `host`, `name`, `user`, `pass` — те, что
   выдал хостинг.
4. **Загрузите файлы** в корень сайта (или в подпапку) по FTP/файловому менеджеру.
5. **Дайте права на запись** папке `uploads` (обычно `755`, на части хостингов `775`) —
   в неё сохраняются фотографии из панели.
6. Откройте сайт. Если вместо страницы появилось сообщение «Нет связи с базой данных» —
   не совпадают доступы в `config.php` либо не импортирован `sql/schema.sql`.

Требования: PHP 8.0 или новее с расширениями `pdo_mysql` и `gd` (есть практически на любом
хостинге), MySQL 5.7+ или MariaDB 10.3+.

## Панель администратора

Открывается кнопкой-шестерёнкой справа внизу или ссылкой «Панель администратора» в подвале.
Пароль по умолчанию — `adamko2026`.

Что редактируется: тексты шапки, главного экрана, блока «о компании» и подвала; логотип
(загрузка файла, высота, подпись рядом, светлая подложка); категории каталога; позиции
с артикулом, характеристиками, описанием и галереей фотографий; преимущества; факты о компании.

Кнопка «Сохранить изменения» записывает всё в базу одной транзакцией — правки сразу видны
всем посетителям, выгружать файлы вручную больше не нужно. Фотографии загружаются на сервер
в папку `uploads`, уменьшаются до 1600 px по длинной стороне и хранятся обычными файлами,
а в базе лежат только пути к ним. Фото, на которые никто больше не ссылается, удаляются
автоматически при следующем сохранении.

### Смена пароля

Пароль хранится хешем. Чтобы поставить свой, выполните на хостинге PHP-строку

```php
<?php echo password_hash('новый-пароль', PASSWORD_DEFAULT);
```

и вставьте полученную строку в `config.php` в поле `admin_password_hash`.

## Каталог

Каталог двухуровневый: **категории** → **позиции**.

- Главная показывает плитки категорий с обложкой (первое фото из позиций категории),
  описанием и числом позиций.
- `catalog.php` — страница каталога: вкладки категорий, описание выбранной, счётчик позиций,
  сетка карточек. Фильтрация серверная, адреса вида `catalog.php?cat=slug` можно давать
  клиентам и ставить в рекламу.
- Ссылка на конкретную позицию — `catalog.php?cat=slug&prod=slug`: страница откроется
  на нужной категории и сразу развернёт карточку товара. Если JavaScript отключён, карточка
  всё равно откроется — она отрисовывается на сервере.
- В шапке выпадающее меню: слева заголовок и ссылка на страницу каталога, в середине
  категории, справа позиции выбранной категории. На компьютере список меняется по наведению,
  на телефоне — по тапу. Клик по позиции ведёт прямо к товару.

Адреса (`slug`) формируются из названий транслитом автоматически при сохранении.

## Структура базы

| Таблица          | Назначение                                                        |
|------------------|-------------------------------------------------------------------|
| `settings`       | тексты и настройки сайта: ключ → значение                          |
| `categories`     | категории каталога: слаг, код, название, описание, порядок          |
| `products`       | позиции: категория, слаг, артикул, название, характеристики, текст |
| `product_images` | фотографии позиций, первая по порядку — главная                     |
| `features`       | блок преимуществ на главной                                         |
| `stats`          | факты о компании                                                    |

Таблицы связаны внешними ключами с каскадным удалением: удаление категории убирает её
позиции, удаление позиции — её фотографии. Всё содержимое можно править и напрямую
в phpMyAdmin — сайт читает данные при каждом запросе.

## Безопасность

- Пароль хранится хешем (`password_hash`), вход — по сессии, с задержкой и блокировкой
  после десяти неудачных попыток.
- Запросы на сохранение и загрузку защищены CSRF-токеном.
- Все запросы к базе — подготовленные выражения, вывод экранируется.
- Загрузка принимает только изображения (проверяется содержимое файла, а не расширение),
  файл пересохраняется средствами GD, имя генерируется случайным.
- `.htaccess` закрывает `config.php`, папки `includes` и `sql`, а в `uploads` запрещает
  выполнение скриптов. На nginx эти правила нужно перенести в конфигурацию сервера.
