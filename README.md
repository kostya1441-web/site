# «Ваш фермер» — интернет-магазин фермерских продуктов (Новокузнецк)

Магазин мяса, птицы, ягоды и домашних заготовок с онлайн-оплатой через эквайринг
Сбербанка и админкой для приёма заказов и ведения каталога.

Написан на чистом PHP 8.1+ без фреймворка и внешних зависимостей: только PDO, GD и cURL.
База данных — MySQL / MariaDB. Дизайн адаптивный: от телефона 360 px до широкого десктопа.

---

## Что внутри

**Витрина**
- Главная с категориями, хитами продаж и новинками
- Каталог с фильтрами (категория, цена, наличие), сортировкой, поиском и пагинацией
- Карточка товара с сопутствующими позициями
- Корзина на AJAX: количество меняется без перезагрузки, счётчик в шапке живой
- Оформление заказа: доставка или самовывоз, оплата онлайн или при получении
- Страницы «О нас», «Контакты» с картой Яндекса и формой вопроса, «Доставка и оплата»
- `robots.txt` и `sitemap.xml` генерируются автоматически

**Оплата (Сбербанк, REST API эквайринга)**
- Регистрация заказа (`register.do`) и переход на защищённую страницу банка
- Проверка статуса (`getOrderStatusExtended.do`) при возврате покупателя
- Приём callback-уведомлений с проверкой подписи HMAC-SHA256
- Возврат средств из админки (`refund.do`)
- Опциональная фискализация (состав чека по 54-ФЗ)
- Тестовый и боевой контуры переключаются одним флагом

**Админка** (`/admin`)
- Дашборд: новые заказы, выручка за день и месяц, средний чек, график за 14 дней,
  топ товаров, товары на исходе
- Заказы: фильтры, карточка заказа, смена статуса с историей, заметки менеджера,
  сверка платежа со Сбербанком, возврат, выгрузка в CSV
- Товары: создание и редактирование, загрузка фото с автоматическим ресайзом,
  быстрые переключатели «показывать» и «хит»
- Категории: полный CRUD с иконками и сортировкой
- Настройки: телефоны, адрес, координаты карты, соцсети, тексты страниц, смена пароля

## Установка

### Требования

- PHP 8.1 или новее, расширения `pdo_mysql`, `gd`, `curl`, `mbstring`
- MySQL 5.7+ или MariaDB 10.3+
- Веб-сервер с корнем в каталоге `public/`

### Установка на хостинге через phpMyAdmin

Консоль не нужна — всё делается через панель хостинга и браузер.

**Шаг 1. Создайте базу данных.**

В phpMyAdmin: вкладка **«Базы данных»** → введите имя (например `u12345_fermer`) →
в списке «Сравнение» выберите **`utf8mb4_unicode_ci`** → **«Создать»**.

Кодировка важна: при `latin1` кириллица в названиях товаров и именах клиентов
превратится в «?????». Установщик проверяет это и предупредит.

**Шаг 2. Заведите пользователя базы.**

У большинства хостингов пользователь создаётся в панели («Базы данных» → «Пользователи»)
и ему выдаются все права на созданную базу. Запишите имя базы, логин и пароль.

**Шаг 3. Загрузите файлы.**

Залейте содержимое репозитория на сервер и направьте домен на папку `public/`.
Если хостинг не позволяет менять корень сайта, загрузите содержимое `public/`
в `public_html/`, остальные папки — уровнем выше, и поправьте путь в
`public_html/index.php` (строка `require dirname(__DIR__) . '/app/bootstrap.php'`).

Выставьте права **775** на папки `storage`, `config` и `public/uploads`.

**Шаг 4. Откройте установщик.**

```
https://ваш-домен.ру/install.php
```

Установщик проверит сервер, попросит данные базы, создаст все таблицы,
администратора и (по желанию) демонстрационный каталог. Файл
`config/config.local.php` он запишет сам.

**Шаг 5. Удалите `public/install.php`.**

Обязательный шаг. Повторный запуск при уже созданном администраторе блокируется,
но файл на боевом сервере оставлять не нужно.

### Установка из консоли

Если доступ к SSH есть:

```bash
git clone <репозиторий> vash-fermer
cd vash-fermer
cp config/config.local.example.php config/config.local.php
# впишите доступы к MySQL в config/config.local.php

php bin/install.php --admin-password=ВашПарольНеКороче8Символов --demo
php -S localhost:8000 -t public
```

Ключи установщика:

| Ключ | Назначение |
|------|-----------|
| `--admin-password=` | пароль администратора (обязательно, минимум 8 символов) |
| `--admin-login=` | логин, по умолчанию `admin` |
| `--demo` | загрузить демонстрационный каталог (23 товара, 5 категорий) |
| `--fresh` | удалить существующие таблицы перед установкой |

### Импорт таблиц вручную

В phpMyAdmin выберите свою базу → вкладка **«Импорт»** → файл
`database/schema.sql` → **«Вперёд»**. Появятся 8 таблиц: `users`, `categories`,
`products`, `orders`, `order_items`, `order_history`, `settings`, `payment_log`.

Дальше всё равно понадобится администратор: его пароль хранится как bcrypt-хеш,
руками такую строку не составить. Проще открыть `install.php` — он увидит готовые
таблицы и просто добавит учётную запись.

### Перенос магазина на другой хостинг

1. В phpMyAdmin старого сервера: база → **«Экспорт»** → «Быстрый» → формат SQL → скачать.
2. На новом сервере создать базу и импортировать этот файл через **«Импорт»**.
3. Скопировать папку `public/uploads` (фотографии товаров) и файл
   `config/config.local.php`, поправив в нём доступы к базе и адрес сайта.

## Настройка

Боевые значения задаются в `config/config.local.php` — этот файл не попадает в git.
За основу возьмите `config/config.local.example.php`:

```bash
cp config/config.local.example.php config/config.local.php
```

### База данных

Доступы хранятся в `config/config.local.php`:

```php
'db' => [
    'host'     => 'localhost',
    'port'     => '3306',
    'database' => 'vash_fermer',
    'username' => 'vash_fermer',
    'password' => '...',
],
```

Кодировка базы — `utf8mb4`, сравнение `utf8mb4_unicode_ci`.
Можно задать и переменными окружения: `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASS`.

### Эквайринг Сбербанка

1. Получите в личном кабинете продавца логин и пароль API (`имя-api`, пароль)
   и секрет для проверки подписи уведомлений.
2. Пропишите их в `config/config.local.php` либо в переменных окружения:

```php
'sber' => [
    'test_mode'      => false,          // true — тестовый контур 3dsec.sberbank.ru
    'username'       => 'логин-api',
    'password'       => 'пароль-api',
    'callback_token' => 'секрет-для-подписи',
    // 'fiscalization' => true,         // включить состав чека по 54-ФЗ
],
```

Переменные окружения: `SBER_USER`, `SBER_PASS`, `SBER_TOKEN`, `SBER_CALLBACK_TOKEN`, `SBER_TEST`.

3. В личном кабинете банка укажите адрес для уведомлений:

```
https://ваш-домен.ру/payment/callback
```

Подпись уведомления проверяется алгоритмом HMAC-SHA256: параметры сортируются по имени,
склеиваются как `ключ;значение;`, результат сравнивается с полем `checksum`.
Уведомление без корректной подписи отклоняется с кодом 403.

Пока доступы не заданы, онлайн-оплата в оформлении заказа недоступна, покупателю
предлагается оплата при получении. Статус подключения виден в админке → Настройки.

### Контакты, карта и тексты

Всё редактируется в админке → **Настройки**: телефоны, адрес, режим работы,
координаты точки на карте, ссылки на соцсети, тексты страницы «О нас», реквизиты.

Координаты берутся из адресной строки Яндекс.Карт: сначала широта, затем долгота.
Значения по умолчанию — центр Новокузнецка.

## Веб-сервер

### Apache

Корень сайта — `public/`. Правила уже описаны в `public/.htaccess`, нужен
включённый `mod_rewrite`. Для HTTPS раскомментируйте блок редиректа в начале файла.

### Nginx + PHP-FPM

```nginx
server {
    listen 443 ssl http2;
    server_name vash-fermer42.ru;
    root /var/www/vash-fermer/public;
    index index.php;

    client_max_body_size 8m;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    # в папке загрузок ничего не исполняем
    location ^~ /uploads/ {
        location ~ \.php$ { deny all; }
    }

    location ~* \.(css|js|jpg|jpeg|png|webp|svg|ico)$ {
        expires 30d;
        access_log off;
    }
}
```

### Права на каталоги

```bash
chown -R www-data:www-data storage public/uploads
chmod -R 775 storage public/uploads
```

## Безопасность

- Все POST-запросы защищены CSRF-токеном, при несовпадении — код 419
- Пароли хранятся через `password_hash()` (bcrypt), при входе — защита от перебора
  (5 неудачных попыток → пауза 10 минут)
- Все запросы к БД — подготовленные выражения, вывод экранируется через `e()`
- Цены и наличие берутся из базы при каждом расчёте корзины: подменить сумму на клиенте нельзя
- Статус страницы «Заказ оформлен» доступен только автору заказа в его сессии
- Загружаемые файлы проверяются по реальному MIME-типу, в `public/uploads/` запрещено
  исполнение PHP
- Реквизиты эквайринга не хранятся в базе и не попадают в репозиторий

## Обслуживание

**Резервная копия:**

База — через phpMyAdmin: выберите базу → **«Экспорт»** → «Быстрый» → SQL → скачать.
Из консоли и вместе с фотографиями товаров:

```bash
mysqldump -u ПОЛЬЗОВАТЕЛЬ -p ИМЯ_БАЗЫ > backups/db-$(date +%F).sql
tar czf backups/uploads-$(date +%F).tar.gz public/uploads
```

**Смена пароля администратора:** админка → Настройки, либо

```bash
php bin/install.php --admin-login=admin --admin-password=НовыйПароль
```

**Журнал платежей** пишется в таблицу `payment_log` — там видны все запросы
к эквайрингу и полученные уведомления.
